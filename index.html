03 / CONCEPTS

CI, CD, and CT are different.

CI

Continuous Integration

Frequently integrate code changes and automatically test them. Goal: find defects early.

CD

Continuous Delivery / Deployment

Prepare tested changes for release; deployment may require approval or happen automatically.

CT

Continuous Training

Retrain a model when a configured trigger occurs, then evaluate it before promotion.

Scope of this implementation

This repository demonstrates a real CI workflow that validates the website and a CD workflow that publishes it to GitHub Pages. The model-quality panel is a front-end simulation; it does not train or evaluate an actual ML model.
